# 보완 동의서 초안: 외부 생성형 AI 서비스를 이용한 학습 과정 분석

> **초안 상태**: 법률·학교 검토 전 초안입니다. `[ ]`로 표시한 곳은 연구자가 사실을 확인해서 채워야 하며, 채우기 전에는 사용하지 마세요. 최종 문구는 학교 개인정보 보호책임자(또는 교육청) 검토를 받은 뒤 확정하세요. 이 문서는 법률 자문이 아닙니다.

## 0. 이 보완 동의서의 구조 (연구자 결정 사항 반영)

- 기존 연구 참여 동의서와 **별도로 분리**해서 받는다. 이 항목에 동의하지 않아도 기존 연구 참여에는 영향이 없다.
- **서명은 학생이 한다. 만 14세 미만 학생은 학부모(법정대리인)도 함께 서명한다.**
- 중학교 1학년에는 만 14세 미만 학생이 있을 수 있으므로, 서명란을 학생별 만 나이(생년월일)로 구분해 확인한다.
- 동의한 학생의 자료만 AI 분석에 쓴다. 동의하지 않았거나 서명이 없는 학생의 자료는 AI 분석에 쓰지 않는다(운영 수칙, 계획서 8절).

## 1. 안내문 (학생·학부모에게 제공)

**[보완 동의서] 학습 과정 분석에 외부 AI 서비스를 사용하는 것에 대한 동의**

앞서 동의하신 연구 「인지적 외주화를 방지하는 시뮬레이터를 활용한 피지컬 프로그래밍」에서, 교사가 학생의 학습 과정을 이해하고 피드백하기 위해 외부 생성형 AI 서비스를 사용하려고 합니다. 이에 관한 내용을 안내드리고 별도로 동의 여부를 여쭙니다.

| 항목 | 내용 |
|---|---|
| 사용 목적 | 교사가 학생의 학습 과정을 이해하고 피드백하는 것을 돕는 분석 보조. AI의 분석은 참고용이며 성적 산출이나 학생 평가의 근거로 쓰지 않습니다. |
| 전송되는 자료 | 학생의 이름·학번 등 식별 정보를 제외한 **학습 행동 요약**: 어떤 부품을 배치했는지, 코드 실행의 성공 여부와 소요 시간, 오류의 종류와 줄 번호, 체크포인트 결과, 도움말(힌트) 사용 단계와 선택 항목 (최근 50건 이내) |
| 전송되지 않는 자료 | 학생의 이름, 학번, 학급 정보, 학생이 작성한 코드 전문, 오류 메시지 본문, 학생이 쓴 글(서술, 설문, 워크시트) |
| 처리하는 자 | `[OpenAI(회사명·법인명 확인)]`, 소재 국가 `[미국 등 — 확인]` |
| 처리 방식 | 인터넷을 통해 해당 서비스의 API로 전송되어 분석 결과가 교사에게 반환됩니다. 서비스 쪽 대화 저장 옵션은 사용하지 않도록 설정되어 있습니다. |
| 서비스 쪽 보관·이용 조건 | `[OpenAI API 데이터 보관 기간, 학습 이용 여부 — 연구자가 약관에서 직접 확인해 기재]` |
| 우리 쪽 보유·파기 | 연구 종료 후 관련 법령에 따라 파기합니다 `[기존 동의서 (아)와 일관되게 기간 명시]` |
| 문의·철회 | 연구자 `[이름·연락처]`. 언제든지 이 항목의 동의를 철회할 수 있으며, 철회 이후의 자료는 AI 분석에 사용하지 않습니다. |
| 거부 시 | 이 항목에 동의하지 않아도 연구 참여와 학교생활에 불이익이 없습니다. 이 경우 교사가 학생의 학습 기록을 직접 보며 피드백합니다. |

## 3. 기존 연구 참여 동의서의 (아) 항목 조정 제안

기존 문구 (아): "…**통계 분석용으로만** 사용되며, 식별이 가능한 정보는 가명 처리되어…"

이 문구는 교사가 개별 학생의 학습 과정을 보고 피드백하는 활용과 맞지 않는 면이 있습니다. 동의서를 새로 배포할 때 다음처럼 목적을 구체화하는 것을 제안합니다 `[학교 검토 후 확정]`.

> 수집된 데이터는 연구 및 교수학습 모델 개발을 위한 통계·질적 분석과, 교사의 학습 과정 이해 및 피드백에 사용됩니다. 식별이 가능한 정보는 가명 처리되며, 연구 목적 이외에는 사용되지 않고 연구 종료 후 관련 법령에 따라 안전하게 파기됩니다.

이미 서명받은 기존 동의서의 문구를 소급해 바꿀 수는 없으므로, 이 조정은 **보완 동의서에 함께 포함**해서 다시 동의받는 방식이 필요한지 학교 책임자에게 확인하세요.

## 4. 사용 전 체크리스트

- [ ] 학교 개인정보 보호책임자 또는 교육청에 문의(처리 위탁·국외 이전 해당 여부, 학교 승인)
- [ ] OpenAI API 데이터 보관 기간·학습 이용 여부를 약관·공식 문서로 확인하고 1절 표에 기재
- [ ] 1절 `[ ]` 항목 모두 채움 (처리자 명칭, 국가, 연락처, 보유 기간)
- [ ] 학교 검토를 거친 최종 문구 확정
- [ ] 보완 동의서 배포·회수 (만 14세 미만은 학부모 서명 확인)
- [ ] 동의한 학생 명단 확정, 비동의·미회수 학생은 AI 분석 대상에서 제외
- [ ] 연구용 코드 대응표에 AI 분석 동의 여부 열 추가(연구자만 접근하는 별도 위치)
- [ ] 이 확인이 끝나기 전에는 플랫폼의 교사용 AI 분석 기능을 사용하지 않는다

## 5. 확인된 전송 범위의 근거 (코드 기준)

- `src/server/ai-learning-analysis.ts`: 이벤트를 `seq`(E1…), `activityId`, `eventType`, 최소화된 `payload`로 변환해 최근 50건만 사용. 오류 이벤트는 종류·줄 번호만 남기고 메시지 본문은 제거. `store:false`로 호출.
- `src/server/teacher-timeline-data.ts`: 이벤트별로 허용된 필드만 남기는 정제 규칙(코드 전문은 제거).
- 학생 이름·학번·학급·등록 ID는 AI 입력에 포함되지 않음 (`docs/project-log.md` D11-B9).
- 이 목록은 현재 코드 기준입니다. 이후 코드가 바뀌어 전송 항목이 달라지면 동의서 안내문도 다시 확인해야 합니다.
